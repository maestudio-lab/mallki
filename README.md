# Mallki

**Gestor de proyectos local-first para Windows.** Un producto de **Kuro Lab**, el área de herramientas computacionales de [MAE Studio](https://www.linkedin.com/company/maestudio-lab/).

Tus proyectos viven en carpetas de tu equipo, como en Obsidian: sin nube obligatoria, sin cuentas y sin perder el control de tus datos. En una sola aplicación de escritorio reúne diagramas de flujo, tableros Kanban, vínculos entre elementos y una biblioteca de recursos. También incluye una API local para conectar tu propia inteligencia artificial.

> *Mallki* (quechua): árbol, ancestro; el puente entre los tres mundos.

---

## Descargar

Descarga el instalador más reciente en **[Releases](https://github.com/maestudio-lab/mallki/releases/latest)**.

- **Requisitos:** Windows 10 u 11, 64 bits.
- **Instalación:** no pide permisos de administrador.
- **Actualizaciones:** la app avisa cuando hay una versión nueva en esta página.

> Las primeras versiones no están firmadas digitalmente. Si Windows SmartScreen muestra un aviso, pulsa **Más información → Ejecutar de todas formas**.
